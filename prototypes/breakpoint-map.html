개발용 CSS

프로토타입은 프레임 폭 기준 @container, 실제 화면은 같은 값의 @media로 쓰면 됩니다.

대상조건CSS

전 앱 — PC1025px 이상@media (min-width:1024.02px)
이로움케어 사업소 — 사이드바(SNB) 숨김1025~1199px@media (min-width:1024.02px) and (max-width:1199px)

왜 1024.02px인가: PC를 min-width:1025px로 쓰면 브라우저 확대·축소로 폭이 1024.5px 같은 소수가 될 때 모바일(max-width:1024px)에도 PC에도 해당하지 않는 틈이 생김 — 소수점으로 두 조건을 맞물림.
사업소 1199 / 대대여 1439는 퍼블 CSS에 이미 있는 값(max-width:1199px, max-width:1439px). 대대여 모바일은 현재 별도 React 앱 — 사업소처럼 PC 화면 안에서 1024px 이하일 때 전환하는 방식으로 바뀌어야 함.
