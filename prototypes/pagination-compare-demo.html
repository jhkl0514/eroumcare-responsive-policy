PC 페이지 목록 — 기본형·조합형(32)

페이지 수를 바꿔 보고 번호를 눌러 보세요. 7페이지 이하는 전부, 8페이지부터 말줄임(앞쪽 1 2 3 4 5 … 끝 / 가운데 1 … 앞 현재 뒤 … 끝 / 뒤쪽 1 … 끝-4 ~ 끝). 결과가 없어도 영역은 보이고 "전체 0/0"만 표시.

모바일 페이지 목록 — 축약형(48)

카드 20개마다 한 페이지. 목록 맨 아래에 ‹ 현재 / 전체 ›(위아래 여백 32). 페이지를 넘기면 목록 맨 위로 이동하고, 카드를 눌러 상세에 갔다가 뒤로 오면 보던 페이지 그대로예요. 0건이면 숨기고 빈 화면 안내만.

팝업 안 목록 — 축약형(48) + 선택

복지용구사업소 등록처럼 팝업 안에서 고르는 목록도 축약형 48. 검색어 입력이 있어서 PC는 480 모달, 모바일은 바텀시트(3-3). "선택"을 누르면 그 줄이 초록 선택 상태가 되고 하나만 고를 수 있어요. 페이지를 넘겨도 고른 사업소는 유지되고, 고르기 전에는 "등록"이 비활성이에요.

선택 동작
  • "선택"을 누르면 버튼이 #f2fde4 배경 + #43a047 테두리·글자 + 체크로 바뀌고, 사업소 이름도 초록 SemiBold. 다른 줄을 고르면 앞의 선택은 풀려요(하나만). 같은 줄을 다시 누르면 선택 해제
  • 줄 어디를 눌러도 선택돼요(모바일에서 버튼만 누르기 어렵지 않게)
  • 검색하면 1페이지부터 다시. 결과가 없으면 "검색 결과가 없습니다." + 페이지네이션 숨김. 3글자 미만이면 "검색" 비활성
  • "등록"을 누르면 팝업이 닫히고 Toast로 결과 안내
