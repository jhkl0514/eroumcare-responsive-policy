상품 변경 — 모바일 바텀시트

Figma 상품변경 3화면(빈 상태 · 입력 중 · 선택 완료)을 그대로 옮겼어요. 검색 입력과 결과 선택이 한 시트 안에서 끝나요. 검색 결과는 입력하는 대로 자동으로 나와요.
  1. "상품변경" → 바텀시트(빈 상태, "상품 변경" 비활성)
  2. 입력칸을 누르면 키보드가 올라오고, 시트는 키보드 위에 붙어요
  3. 입력하면 결과가 입력칸 아래 패널에 자동으로 나와요 (예: "NY", "1300", "침대", "없음")
  4. 결과를 누르면 입력칸에 상품명이 들어가고, 패널과 키보드가 닫히고 "상품 변경"이 활성화돼요
  5. 입력칸을 다시 누르면 글자 전체가 선택돼서 바로 새 검색어를 칠 수 있어요(지우기 X가 없어서)
  6. 돋보기나 키보드 "검색" 키를 누르면 키보드가 닫혀 결과를 넓게 볼 수 있어요
3-5바텀시트 · 키보드 위 최대 높이 · 본문만 스크롤
3-2입력칸 MO 48 · 포커스 2px · 돋보기 = 검색 버튼, X 없음
3-7결과 패널 = 옵션 패널, 행은 SelectOption MO 44(누르는 순간 틴트), 품절은 선택 불가
3-3하단 버튼 54 · 위·아래 32 · 선택 전 비활성
