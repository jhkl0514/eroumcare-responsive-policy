검색 영역 — PC 검색 패널 ↔ 모바일 필터칩+바텀시트 — CLAUDE.md 3-7. 검색은 리스트 화면에만 있으므로 적응형(PC 패널 / 모바일 칩+시트를 둘 다 준비해두고 1024/1025px 경계에서 표시만 전환). 상세 화면은 반응형. Figma 입출고 창고 입고처리 실측:
  • PC: 회색 패널(#fafafa, 테두리 #bdbdbd, radius 4, 패딩 16) 안에 라벨 120px + 체크박스 그룹 행을 2열로 나열(행 높이 44, 하단 구분선 #eee). 첫 행은 날짜(기준 셀렉트 160 + 시작일/종료일 각 160 + 기간 세그먼트 오늘/어제/일주일/지난달/3개월). 체크박스는 복수 선택 — 기본은 "전체"만 체크, "전체"를 누르면 같은 행 모두 체크. 셀렉트·달력은 DS 컴포넌트(옵션 패널 / calendar_Default 팝오버). 검색어는 셀렉트(160) + 입력(264). 하단 가운데 초기화(아웃라인)/검색(필드) 각 130×36. 우상단 접기 버튼 — 기본 펼침, 접으면 라벨이 "상세"로 바뀜
  • 모바일: 패널이 사라지고 ① 필터칩 줄(기본은 "이름 : 전체", 값을 고르면 값만 표시 + 우측 고정 "검색" 칩) ② 적용 태그 줄(초록 #09af00 글씨 + X, 우측 고정 "초기화" — 적용된 조건이 있을 때만) ③ 건수 순으로 쌓임
  • 칩 탭 → 단일 선택 시트(선택 행만 틴트 #eff1fd+체크, "선택완료"). "검색" 칩 탭 → 검색 시트(필터별 버튼 그리드 2/3열 + 상세검색 입력, 하단 초기화 120px + 검색). 모바일은 모든 필터 한 개만 선택

체크박스는 복수 선택 — 처음엔 "전체"만 체크. 다른 항목을 누르면 "전체"가 풀리고, 그 뒤 "전체"를 누르면 같은 행 항목이 모두 체크됨(다시 누르면 모두 해제). 개별 항목을 전부 체크해도 "전체"가 체크됨 — 기획 합의 사항(퍼블 동작과 동일). 셀렉트를 누르면 DS 옵션 패널(선택 항목 틴트 #eff1fd+브랜드색 굵게+체크), 날짜 필드를 누르면 DS 달력(calendar_Default, 선택일 #90ee02, 호버 #f2fde4, 이전/다음 달 #bdbdbd)이 열림. 세그먼트를 누르면 날짜가 자동으로 채워지고, 달력에서 날짜를 직접 고르면 세그먼트 선택이 풀림. 우상단 접기를 누르면 날짜 행과 버튼만 남고 버튼 라벨이 "상세"로 바뀜(검색·초기화 버튼은 유지).
