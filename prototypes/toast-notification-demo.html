  • 실사용 variant: Success · Error만 사용 — Default(흰 배경)는 실제로 쓴 적 없어 제외. Description(보조 설명 줄)도 사용 안 함 — 본문 한 줄만
  • 색상: Success — 배경 #e8f5e9 / 테두리 #43a047 / 체크 아이콘 #166534. Error — 배경 #ffebee / 테두리 #e53935 / 원형 X 아이콘 #e53935
  • 구조: 패딩 8px 16px, 높이 62px, radius 8px, 테두리 1px. 아이콘 24×24 + 간격 8px + 본문 16px SemiBold(#1a1a1a)
  • 닫기(X) 버튼: 실제 적용한 적 있음 — 우측 24×24 닫기 아이콘(#333). Action 텍스트 버튼은 사용 안 함
  • 그림자(elevation/shadow3): 0 2px 4px rgba(0,0,0,.12), 0 0 2px rgba(0,0,0,.12)
  • 크기·위치: PC 520px 고정폭, 모바일 화면폭의 80%. 화면 하단 중앙, PC 하단 48px / 모바일 28px, z-index:900
  • 동작: 닫기 버튼 없으면 2초 후 자동 소멸, 닫기 버튼 있으면 사용자가 X로 닫을 때까지 유지. 여러 개는 flex-direction:column-reverse(새 토스트가 위로)
