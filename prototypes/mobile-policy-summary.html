모바일 반응형 한눈에

모바일(1024px 이하) 화면을 만들 때 자주 헷갈리는 규칙만 모았어요. 자세한 내용은 각 항목 오른쪽 조항 링크(원문)에서 확인하세요.

1기준 — 1024px 이하는 모바일, 한 페이지로원문 1·2

  • 1024px 이하 = 모바일, 1025px 이상 = PC. CSS: 모바일 max-width:1024px / PC min-width:1024.02px
  • 360px은 최소 지원폭일 뿐, 360에서 따로 바뀌는 규칙은 없어요(768도 마찬가지)
  • 모바일을 별도 페이지(URL)로 만들지 않아요(*_mobile.html 분리 금지). 대신 화면 종류에 따라 구조가 달라요
    화면모바일 구조
    목록모바일 전용 구조(카드 등)를 따로 만들어, PC 테이블과 함께 한 페이지에 넣고 1024px 이하에서 표시만 바꿔요(적응형)
    상세PC 구조 하나를 그대로 반응형으로 재배치해요(모바일 구조를 따로 만들지 않음)

6키보드·검색원문 3-12

  • 키보드가 올라오면 바텀시트는 키보드 위에 붙고, 남은 공간 안에서 최대 높이까지 커져요. 본문만 스크롤
  • 하단 버튼은 키보드 위에 붙고 입력칸을 가리지 않아요
  • 키보드가 닫히는 때: 선택 완료, "완료"·"검색" 키, 바깥 빈 곳 탭, 시트 닫기
  • 검색 결과는 입력하는 대로 자동 표시(약 0.3초 간격). 돋보기·"검색" 키는 키보드를 닫아요
  • 검색칸에는 지우기 X가 없어요(오른쪽 돋보기 고정). 다시 누르면 글자 전체 선택. type="search"의 브라우저 기본 ×는 CSS로 숨겨요
  • 숫자 칸은 숫자 키패드(inputmode="tel"), 엔터로 폼을 바로 제출하지 않아요

8목록·상세원문 3-7·3-9·3-11

  • 목록: PC 테이블 ↔ 모바일 카드(모바일 전용 구조)를 둘 다 두고 표시만 전환. 카드를 누르면 상세로
  • 모바일 페이지네이션 — 확인 중: 지금 정책은 "페이지네이션 없이 스크롤로 이어서 불러오기"예요. 모바일에도 페이지네이션을 넣는 쪽으로 검토하고 있어서, 결정될 때까지 기존 페이지네이션을 지우지 말고 그대로 두세요
  • 검색 영역: 모바일 필터칩(32) — 기본값일 땐 "이름 : 값"(예: "상태 : 전체"), 고르면 값만. 모바일 필터는 모두 단일 선택. 시트를 열면 현재 값이 처음부터 선택 표시. 기간 기본값(3개월 등)은 처음부터 선택 상태
  • 상세: 정보 표는 PC 한 줄 2쌍 → 모바일 1쌍. 본문 맨 아래 "○○목록" 버튼 + 상단 뒤로가기(48×48), 연락처는 tel: 링크
  • 화면 좌우 여백 20, 카드 사이 12, 상단에 상태가 붙는 카드 패딩 16 16 24 16

9자주 묻는 질문

모바일에서 모달은 Full로 가는 거 아닌가요?
아니요. 모든 모달은 min(크기, 100% - 40px)예요. 폰에서는 좌우 20만 남기고 거의 꽉 차 보이고, 태블릿에서는 원래 크기(480 등)로 떠요.
PC에 340 모달이 있나요?
없어요. PC는 480 / 600 / 800이에요.
모달 버튼도 PC 고정인가요?
높이는 네(48). 폭은 아니요 — 모바일은 Full, 150 고정은 PC에서만.
모달 안 셀렉트도 48로 키우나요?
네, 예외 없이 1024px 이하면 48·16px이에요. 디자인은 PC 모달 하나로 관리해요.
입력칸이 48이면 옆 버튼(우편번호)도 48인가요?
아니요. 버튼은 PC 크기(SM 36) 그대로 두고 입력칸 높이의 가운데에 맞춰요.
바텀시트는 모바일 모달 전부에 쓰나요?
아니요. 글자를 입력하는 팝업(사유·주소·검색)만이에요. 안내·확인·선택만 하는 팝업은 모바일에서도 모달이에요.
하단 고정 버튼이 뭔가요?
모바일에서 화면 아래에 sticky(fixed)로 붙는 버튼이에요. LG 54, 아래 여백 20 + safe-area.
반응형이면 PC 컴포넌트를 그대로 써도 되나요?
입력류는 아니에요 — 1024px 이하에서 모바일 크기로 바꿔요. 버튼·칩·탭은 PC 크기 그대로예요.

10공통 CSS (페이지별 예외 없이 이것만)원문 3-2

/* 모달 폭 — 미디어쿼리 없음 */
.modal { width: min(var(--modal-w, 480px), calc(100% - 40px)); }

/* 버튼 — PC·모바일 같은 값 */
.btn-sm { height: 36px; }  .btn-md { height: 48px; }  .btn-lg { height: 54px; }

/* 1024px 이하: 입력류만 모바일 크기 */
@media (max-width: 1024px) {
  .input, .select   { height: 48px; padding: 12px; font-size: 16px; }
  .select-option    { min-height: 44px; padding: 10px 8px 10px 12px; font-size: 16px; }
  textarea          { font-size: 16px; }
  .modal-actions .btn { flex: 1; }          /* 모달 버튼 폭 Full */
}
@media (min-width: 1024.02px) {
  .modal-actions .btn { flex: 0 0 150px; }  /* 모달 버튼 PC 150 고정 */
}
