  • 1024 외에 별도 브레이크포인트는 쓰지 않습니다(360은 모바일 최소 지원폭). Figma의 768 프레임은 모바일 레이아웃이 태블릿 폭에서 늘어난 모습을 보여주는 예시일 뿐, 별도 기준이 아닙니다.

  • 필터 태그 줄
  • 결과 정보 — 검색결과 N명, 급여 잔액 총액

3. 컴포넌트별 규칙

상세 조건 패널

  • 기본 상태는 접힘입니다.
  • 버튼 라벨은 상태와 맞춥니다. 접혀 있으면 "상세 조건 펼치기", 펼쳐져 있으면 "상세 조건 접기"입니다.
  • 열고 닫을 때 슬라이드 애니메이션을 적용합니다. 즉시 보였다 사라지는 방식은 쓰지 않습니다.
  • 본문은 섹션별 라디오·체크박스이고, 하단에 초기화(아웃라인)·적용(필드) 버튼이 있습니다.

필터 태그 (신규 컴포넌트)

  • 조건을 적용하면 패널 아래에 칩으로 표시합니다.
  • 스타일: 기본 배경 #eff1fd, 글자 14px SemiBold #141e76, radius 999, 높이 32, 패딩 6/12, 오른쪽에 X
  • X를 누르면 그 조건만 해제되고 결과를 바로 다시 조회합니다. 마우스를 올리면 X를 강조합니다.
  • 표시 순서는 고정입니다: 급여 잔액 → 적용구간 → 대여종료 → 자격상실 제외

  • 테두리 1px #bdbdbd, radius 4, 카드 사이 간격 12px, 본문 패딩 16 16 24 16

  • 본문(패딩 16)
  • PC: 좌측에 정보 2행(등급/본인부담률 + 급여 잔액 → 유효기간 + 적용구간), 우측에 메모
  • 폭이 줄어 줄바꿈되면 적용구간이 마지막 행으로 내려와 대여종료 예정 박스와 붙어 있어야 합니다.
  • 모바일: 한 줄에 하나씩 등급/본인부담률 → 급여 잔액 → 유효기간 → 적용구간(라벨 왼쪽, 값 오른쪽), 바로 아래 대여종료 예정 박스, 메모는 카드 정보 아래로 이동
  • 하단 버튼
  • PC: 오른쪽 정렬로 수급자 정보수정 · 욕구사정기록지 작성 · 수급자 상세보기
  • 모바일: 보조 버튼 2개 나란히 + "수급자 상세보기" 전체폭
