디자인 시스템 UX 제안 제안 · 미확정

DS 확정이 아니라 제안입니다. 체크박스·라디오 문서(design-system/components/checkbox.md·radio.md)에 '정의 없음'으로 남은 두 가지를 화면으로 비교합니다. 확정되면 design-system/에 반영합니다. 상품명은 모두 예시입니다.

화면 폭

DS-U1 그룹 오류 표시 (체크박스·라디오) 제안 · 미확정

필수 선택 그룹을 비운 채 저장하면 그룹 아래에 DS 입력칸 오류와 같은 문구(.ds-field__error)를 띄웁니다. 항목 테두리는 바꾸지 않습니다.

현행 — 오류 표시 없음

저장을 눌러도 화면에 아무 표시가 없어, 무엇이 빠졌는지 알 수 없습니다.

제안 — 그룹 아래 오류 문구

저장하면 첫 오류 그룹으로 이동하고, 하나라도 고르면 그 그룹의 문구가 바로 사라집니다.

제안 규칙
  • 문구: 라디오 "취소 사유를 선택해 주세요." / 체크박스 "변경할 상품을 1개 이상 선택해 주세요." — .ds-field__error, 그룹 바로 아래
  • 그룹에 aria-invalid="true" + aria-describedby로 문구 연결, 항목 테두리·색은 그대로
  • 저장 시 첫 오류 그룹으로 스크롤 · 그 그룹에서 하나라도 선택하면 문구 즉시 제거

DS-U2 체크박스 부분 선택 (Indeterminate) 제안 · 미확정

표의 일부 행만 선택했을 때 머리 체크박스에 흰 가로선(−)을 보여 "일부 선택" 상태를 알립니다.

현행 — 부분 선택 표시 없음

일부만 골라도 머리 체크박스가 빈칸이라, 선택된 행이 있는지 한눈에 알 수 없습니다.

제안 — 머리 체크박스에 가로선(−)

없음 → 누르면 전체 선택 → 누르면 전체 해제 / 일부 선택(−) → 누르면 전체 선택

제안 규칙
  • 일부 선택: 머리 체크박스 선택 배경(--ds-color-darkblue-600) + 흰 가로선 10×2 — 접근성은 indeterminate + aria-checked="mixed"
  • 머리 체크박스 동작: 없음 → 전체 선택 → 전체 해제, 일부 → 전체 선택
  • 선택 행 배경 --ds-color-darkblue-50(3-9), 체크 열 44px
