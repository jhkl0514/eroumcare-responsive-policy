3-1. 텍스트형 (읽기전용 정보 테이블) — CLAUDE.md 규칙 원문:
  • 헤더(라벨) 셀: max-width:128px; min-width:80px (배경 있음, #f5f5f5)
  • 값 셀: min-width:160px
  • flex-shrink만 사용, wrap 없음 — 헤더가 128→80까지, 값이 자기 min-width까지 줄어들며 버틴다. 최소 240px(80+160)까지는 좌우 2열 유지 → 별도 스택 폴백 불필요
  • 배경 없는 버전(예: 회수정보 조회형)은 라벨 125px, 배경 없음
이 유형은 PC/모바일이 구조 자체는 안 바뀌는 반응형 컴포넌트라, "PC 화면 / 모바일 화면"이 아니라 같은 컴포넌트를 담은 컨테이너 폭을 바꿔서 비교합니다 — 넓을 때와, 최소 지원폭인 240px일 때 둘 다 좌우 2열이 그대로 유지되는지 확인하는 게 포인트입니다.
