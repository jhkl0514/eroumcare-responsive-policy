3-4. 액션 버튼 배치 — CLAUDE.md 규칙 원문 그대로:
  • PC: 페이지 타이틀 옆(우측), Hug 사이즈(텍스트+패딩만큼만, flex:0 0 auto) — 전체폭 분할 금지
  • 모바일: 타이틀 아래로 이동 + 화면 하단 sticky 플로팅(흰색 그라데이션 페이드), 각 버튼은 폭을 나눠 가짐(Full)
  • 모바일 하단 sticky 요소는 env(safe-area-inset-bottom) 필수 (노치/홈 인디케이터 대응)
이 페이지는 화면 하나를 프리셋 폭으로 전환하는 대신, PC/모바일을 나란히 놓고 "이 규칙이 실제로 이렇게 적용된다"를 바로 비교해보는 시험용 포맷입니다. 모바일 쪽은 실제로 스크롤해보면 하단 버튼바가 sticky로 붙는 걸 확인할 수 있습니다.
