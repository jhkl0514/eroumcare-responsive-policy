운영관리 셸 — SideNav ↔ 모바일 전체메뉴 전환 — CLAUDE.md 9-1. 대상: 입출고 창고 · 설치파트너 전용(이로움케어 사업소는 실제 서비스가 구버전 GNB/SNB/Footer를 그대로 쓰고 있어 이 구조에서 제외 — 9-1 참고):
  • PC: GNB 56px(미니멀 — 햄버거+로고+공지+계정아이콘만) + SideNav 240px + 콘텐츠(실제론 1136px, 이 데모는 축소 표현)
  • 모바일: SideNav가 사라지고 상단 GNB_로그인전(56px)이 브랜드색(#323da3) 배경 + 흰색 페이지 타이틀 + 우측 햄버거(48×48)로 바뀜 — 이 햄버거가 전체메뉴를 여는 실제 트리거
  • 햄버거 탭 → 전체메뉴 전체화면 오버레이: 상단 상태바(28px) + Navigation(56px, 흰 배경+"전체메뉴"+닫기) → 프로필 카드(아바타48px+이름/소속+로그아웃) → 두꺼운 구분선(8px) → 메뉴 리스트(Sidemenu_Items, PC 42px → 모바일 48px로 터치 영역 확대) → 카피라이트
정정(2026-09-28) 이전 버전은 하단에 "햄버거/닫기/뒤로가기" 3아이콘 유틸리티 바를 앱 내비게이션으로 잘못 모델링했었음. Figma 재확인 결과 그 하단 System_navigation은 Android 3버튼 내비게이션(최근앱/홈/뒤로가기) 같은 OS 레벨 시스템 chrome 목업이었고, 우리 앱이 실제로 그리는 요소가 아님 — 실제 트리거는 상단 GNB의 햄버거였음이 확인되어 이번에 구조를 바로잡음. 아래 모바일 쪽 햄버거 버튼을 눌러보면 실제 전체메뉴 전환을 시뮬레이션할 수 있습니다.
