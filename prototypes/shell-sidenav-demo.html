  • PC: GNB_로그인전 56px(브랜드색 #323da3 배경 — 햄버거+흰색 로고 / 공지사항+아바타) + SideNav 240px + 콘텐츠(실제론 1136px, 이 데모는 축소 표현). GNB 햄버거를 누르면 SideNav가 왼쪽으로 슬라이드되며 숨겨지고, 다시 누르면 나타남
  • 모바일: SideNav가 사라지고 상단 GNB_로그인전(56px)이 브랜드색 배경 + 흰색 페이지 타이틀 + 우측 햄버거(48×48)로 바뀜 — 이 햄버거가 전체메뉴를 여는 트리거
  • 햄버거 탭 → 전체메뉴 전체화면 오버레이: 상단 상태바(28px) + Navigation(56px, 흰 배경+"전체메뉴"+홈/닫기) → 프로필(아바타48px+사업소명+로그아웃 — 회색 Filled 버튼) → 두꺼운 구분선(8px) → 메뉴 리스트(Sidemenu_Items, PC 42px → 모바일 48px로 터치 영역 확대, 활성 표시 없음) → "이로움케어 메인 바로가기" 카드(연두 #f2fde4, radius 16) → 하단 카피라이트

콘텐츠 최소 폭 1440px 유지 — 창이 좁으면 가로 스크롤
1440px 이상: GNB 좌측 햄버거(전체보기)를 눌러보세요 — SideNav가 왼쪽으로 스르르 사라지고 콘텐츠가 전체폭으로 넓어집니다. 이때 햄버거 아이콘도 가운데 줄이 짧아지는 모양으로 애니메이션되며 바뀜(0.3s). 다시 누르면 SideNav가 나타나고 아이콘도 세 줄 같은 길이로 돌아감. 상위 메뉴(42px, Bold)와 하위 메뉴(40px, Regular+불릿), 선택된 하위 메뉴는 연한 브랜드 틴트(#e3e5f5) 배경 + 브랜드색 텍스트.
1025~1439px(위 버튼으로 전환): SideNav가 처음부터 숨겨져 있고, 햄버거를 누르면 콘텐츠 위에 겹쳐 열림(오버레이). 콘텐츠는 최소 폭 1440px을 유지하고 가로 스크롤 — 퍼블 CSS(max-width:1439px) 구현을 규칙으로 채택(CLAUDE.md 1번 "PC 축소 구간").
Mobile 1024px 이하 — 상단 GNB 햄버거 + 전체메뉴 오버레이 (예시: 사업소 — 3개 앱 공통 구조)
