Text input

이름·전화번호·주소처럼 사용자가 직접 타이핑하는 짧은 한 줄 값을 받는 입력칸입니다.

Figma · Textfield ↗ 정책 3-2 입력 폼과 입력칸 ↗ PC 40 · 모바일 48

개요

아래 칸을 눌러 직접 입력해 보세요. 값이 생기면 오른쪽에 지우기(X)가 나타나고, 누르면 값만 지워지고 커서는 칸에 남습니다.

숫자만 입력해 주세요.

기기
상태

언제 쓰나요

  • 사용자가 직접 타이핑하는 한 줄 값 — 이름, 휴대폰번호, 상세주소, 요양인정번호
  • 정해진 선택지에서 고르는 값은 Select, 여러 줄 메모·사유는 Textarea를 씁니다.
  • 날짜는 달력, 검색어는 검색 입력(오른쪽 돋보기 버튼, 지우기 없음)으로 구분합니다. 3-2

구조

입력칸은 라벨, 칸, 도움말 세 줄로 이루어집니다. 왼쪽 아이콘과 지우기는 필요할 때만 붙입니다.

동·호수까지 입력해 주세요.

  1. 1라벨 — 무엇을 입력하는지. 항상 보입니다.
  2. 2필수 표시 — 라벨 바로 뒤 빨간 *.
  3. 3입력칸 — 상태에 따라 테두리·배경이 바뀝니다.
  4. 4값 / placeholder — placeholder는 형식 힌트일 뿐 라벨을 대신하지 않습니다.
  5. 5지우기 — 값이 있고 수정 가능할 때만. 아이콘 24.
  6. 6도움말 / 오류 — 아이콘 24 + 문구. 오류일 때 빨간색으로 바뀝니다.

상태

상태는 6가지입니다. Focused·Error는 테두리가 2px로 두꺼워지지만 글자 위치는 그대로입니다.

사용 원칙

이렇게

라벨은 항상 보이게 두고, placeholder는 입력 형식만 알려 줍니다.

이렇게 하지 않기

placeholder로 라벨을 대신하면 입력을 시작하는 순간 무엇을 쓰는 칸인지 사라집니다.

휴대폰번호 11자리를 입력해 주세요.

이렇게

오류는 빨간 테두리와 함께 무엇을 고쳐야 하는지 문장으로 알려 줍니다.

이렇게 하지 않기

테두리 색만으로는 무엇이 틀렸는지 알 수 없고, 색을 구분하기 어려운 사용자는 오류를 놓칩니다.

이렇게

버튼으로만 채우는 칸(우편번호·기본주소)은 ReadOnly. 값이 진하게 읽힙니다. 3-2

이렇게 하지 않기

Disabled는 “지금 쓸 수 없음”입니다. 값이 흐려져 확인해야 할 주소가 잘 안 보입니다.

이렇게

검색 입력은 오른쪽 돋보기 버튼 하나. 칸을 다시 누르면 글자 전체가 선택됩니다. 3-2

이렇게 하지 않기

지우기와 돋보기를 나란히 두면 누를 곳이 겹쳐 잘못 누르기 쉽습니다.

불러오기

토큰 → 컴포넌트 CSS → 동작 스크립트 순서로 넣습니다. 지우기 버튼과 셀렉트는 ds.js가 자동으로 연결합니다.

<link rel="stylesheet" href="design-system/css/components.css">

기본 마크업

라벨·칸·도움말을 .ds-field로 묶습니다. 아이콘이나 지우기가 없으면 <input class="ds-input"> 하나로도 됩니다.

<div class="ds-field">
  <label class="ds-field__label" for="tel">휴대폰번호<span class="ds-field__required">*</span></label>
  <div class="ds-input">
    <input class="ds-input__control" id="tel" inputmode="tel" enterkeyhint="next"
           placeholder="010-0000-0000" required aria-describedby="tel-help">
    <button class="ds-input__clear" type="button" aria-label="휴대폰번호 지우기"></button>
  </div>
  <p class="ds-field__hint" id="tel-help">숫자만 입력해 주세요.</p>
</div>

<!-- 아이콘·지우기 없는 단순형 -->
<input class="ds-input" placeholder="이름 입력">

상태 만들기

상태방법
Inactive값이 비어 있으면 자동(:placeholder-shown). placeholder는 비워 두지 말고 형식 힌트를 넣습니다.
Default값이 있으면 자동
Focused입력 중이면 자동(:focus-within)
Errorinput에 aria-invalid="true" + <p class="ds-field__error">를 aria-describedby로 연결
Disabledinput에 disabled
ReadOnlyinput에 readonly (지우기 버튼은 자동으로 숨음)

</div>
<p class="ds-field__error" id="tel-err">휴대폰번호 11자리를 입력해 주세요.</p>

AI 코딩용 요약

바이브 코딩할 때 프롬프트에 그대로 붙여 넣는 규칙입니다.

[Text input 규칙 — 이로움케어 DS]
- 마크업: .ds-field > .ds-field__label + .ds-input(> .ds-input__control + .ds-input__clear) + .ds-field__hint|.ds-field__error
- 크기: PC 40 / 1024px 이하 48 (CSS가 자동 전환). 글자 14 / 16. 좌우 여백 12. 모서리 4
- 상태: 빈 칸=Inactive, 값 있음=Default, 입력 중=Focused(2px #323DA3), aria-invalid=Error(2px #E53935 + 문구),
        disabled=Disabled(#EEE·흐린 글자), readonly=ReadOnly(#EEE·진한 글자)
- 지우기(X): 값이 있고 수정 가능할 때만. 검색 입력·ReadOnly·Disabled·날짜·셀렉트에는 없음
- 버튼으로만 채우는 칸(우편번호 등)은 readonly. 옆 버튼은 .ds-btn--field (PC 36 칸 가운데 · 모바일 48)
- placeholder로 라벨을 대신하지 않는다. 오류는 반드시 문장으로 안내
- 폼 배치: 라벨 125 고정 + 입력 영역 min 280, flex-wrap(미디어쿼리 없음), PC 입력 영역 max 480
