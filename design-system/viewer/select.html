Select

정해진 선택지 중 하나를 고르는 칸입니다. 누르면 아래에 옵션 목록이 열립니다.

Figma · SelectField ↗ Figma · SelectOption ↗ 정책 3-2 입력칸 ↗ 정책 3-7 검색 영역 ↗

개요

칸을 눌러 목록을 열고 골라 보세요. 키보드로는 ↓로 열고 ↑↓로 이동, Enter로 고릅니다. 옵션이 6개를 넘으면 목록 안에서 스크롤됩니다.

언제 쓰나요

  • 정해진 값 중 하나를 고를 때 — 검색 기준, 주문 상태, 배송요청사항
  • 직접 타이핑하는 값은 Text input, 여러 개를 고르면 체크박스를 씁니다.
  • 모바일 리스트 필터는 셀렉트 대신 필터칩 + 단일 선택 시트로 엽니다. 3-7

구조

SelectField(칸)와 OptionGroup(옵션 패널), SelectOption(옵션 행) 세 부품으로 이루어집니다.

주문 상태
  1. 1라벨 — 무엇을 고르는지.
  2. 2칸(SelectField) — 입력칸과 같은 크기·상태 규칙.
  3. 3현재 값 — 고르기 전에는 회색 placeholder.
  4. 4화살표 — 24. 목록이 열리면 위로 뒤집힙니다.
  5. 5옵션 패널(OptionGroup) — 칸 아래 4, 같은 폭.
  6. 6선택된 옵션 — 연한 파란 배경으로 현재 값 표시.

사용 원칙

이렇게

목록을 열면 현재 값이 처음부터 선택 표시되어 있습니다.

이렇게 하지 않기

어떤 값이 골라져 있는지 목록에서 다시 찾아야 합니다.

검색 기준

이렇게

옵션 이름은 짧은 명사로. 표의 컬럼 이름과 같게 맞춥니다. 3-7

검색 기준

이렇게 하지 않기

문장형 옵션은 칸에서 잘리고 서로 비교하기 어렵습니다.

이렇게

DS 셀렉트를 씁니다. 목록 모양·크기가 어느 기기에서나 같습니다.

이렇게 하지 않기

브라우저 기본 <select>는 기기마다 모양이 달라 DS와 맞지 않습니다. 3-7

불러오기

열기·닫기·키보드·바깥 클릭 닫기는 ds.js가 처리합니다. 마크업만 맞추면 됩니다.

<link rel="stylesheet" href="design-system/css/tokens.css">
<link rel="stylesheet" href="design-system/css/components.css">
<script defer src="design-system/js/ds.js"></script>

기본 마크업

<div class="ds-field">
  <span class="ds-field__label" id="status-label">주문 상태</span>
  <div class="ds-select">
    <button class="ds-select__trigger ds-is-inactive" type="button"
            aria-haspopup="listbox" aria-expanded="false" aria-labelledby="status-label">
      <span class="ds-select__value ds-is-placeholder">선택</span>
      <span class="ds-select__chevron"></span>
    </button>
    <div class="ds-select__list" role="listbox" aria-labelledby="status-label" hidden>
      <button class="ds-select__option" type="button" role="option" aria-selected="false" data-value="new">신규배정</button>
      <button class="ds-select__option" type="button" role="option" aria-selected="false" data-value="checking">주문확인중</button>
      <button class="ds-select__option" type="button" role="option" aria-selected="false" aria-disabled="true">취소요청</button>
    </div>
  </div>
</div>

값이 이미 있으면 ds-is-inactive·ds-is-placeholder를 빼고, 해당 옵션에 aria-selected="true"를 줍니다.

상태 만들기

상태방법
Inactivetrigger에 .ds-is-inactive, 값에 .ds-is-placeholder (선택하면 ds.js가 제거)
Focused열리면 자동(aria-expanded="true"), 키보드 포커스는 :focus-visible
Errortrigger에 aria-invalid="true" + .ds-field__error 문구
Disabledtrigger에 disabled
ReadOnlytrigger에 .ds-is-readonly (눌러도 열리지 않음)
옵션 Disabled옵션에 aria-disabled="true"

AI 코딩용 요약

바이브 코딩할 때 프롬프트에 그대로 붙여 넣는 규칙입니다.

[Select 규칙 — 이로움케어 DS]
- 네이티브 <select> 금지. .ds-select > button.ds-select__trigger(.ds-select__value + .ds-select__chevron) + .ds-select__list[role=listbox] > button.ds-select__option[role=option]
- ds.js가 열기/닫기/키보드/바깥 클릭/하나만 열기를 처리. 값 변경은 ds-change 이벤트
- 칸: PC 40 / 1024px 이하 48, 상태 규칙은 Text input과 동일(열림 = Focused 2px #323DA3)
- 옵션 패널: 칸 아래 4, 패딩 8, 테두리 1px #333, radius 4, shadow3, 옵션 6개까지 보이고 스크롤
- 옵션 행: PC 36 / 모바일 44. 선택 #EFF1FD, hover #EEE, 선택+hover #CED2F4, disabled #EEE
- 현재 값은 목록을 열 때부터 선택 표시. 옵션 이름은 짧은 명사(표 컬럼 이름)
- 모바일 리스트 필터는 셀렉트가 아니라 필터칩 + 단일 선택 시트(정책 3-7)
