색

아이콘 색은 Figma 의미 색(Color/icon/*)을 씁니다. 글자 옆 아이콘은 글자와 같은 색을 따라갑니다.

예외 — 도움말은 아이콘 #333 · 글자 #616161로 색이 다릅니다(Figma Textfield). Text input

사용 원칙

이렇게

뜻이 분명한 아이콘(돋보기 = 검색)만 글자 없이 씁니다. 화면 읽기용 이름은 꼭 붙입니다.

이렇게 하지 않기

뜻이 여러 가지인 아이콘(계약서 확인 등)은 글자 없이 쓰면 무엇을 하는지 알 수 없습니다.

이렇게

24 그대로. 옆 아이콘·글자와 크기와 줄이 맞습니다.

이렇게 하지 않기

27처럼 단계에 없는 크기는 옆 아이콘보다 커 보이고 줄이 어긋납니다.

파일

아이콘마다 SVG 파일이 있고, 모든 아이콘을 담은 icons.js도 있습니다. 채움색은 currentColor라 CSS color로 바꿉니다.

design-system/icons/search.svg      ← 아이콘 하나 (이름은 소문자)
design-system/icons/icons.js        ← window.DS_ICONS = { "search": { figma, node, w, h, svg } }

<!-- 1) 파일 그대로 -->
<img src="design-system/icons/search.svg" width="24" height="24" alt="">   (색 바꿀 수 없음)

<!-- 2) 색을 바꾸려면 mask -->
<span class="icon" style="--icon:url(design-system/icons/search.svg)"></span>
.icon { width: 24px; height: 24px; background: currentColor; -webkit-mask: var(--icon) center / contain no-repeat; mask: var(--icon) center / contain no-repeat; }

입력칸 · 셀렉트 · 지우기 · 도움말 · 오류 · 닫기 아이콘은 components.css 안에 이미 들어 있어 따로 넣지 않아도 됩니다.
