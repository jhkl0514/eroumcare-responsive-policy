Button

저장·검색·주문하기처럼 동작을 실행하는 버튼입니다. 크기는 화면 폭이 아니라 놓이는 자리로 고릅니다.

Figma · Button ↗ 정책 3-4 액션 버튼 배치 ↗ SM 36 · MD 48 · LG 54

개요

종류·위계·크기를 바꿔 보고, 버튼에 마우스를 올려 눌림 색을 확인해 보세요.

위계
크기

종류와 상태

한 영역의 주 동작은 Filled Default 하나. 보조 동작은 Secondary나 Outline으로 한 단계 낮춥니다. 눌림 표현은 버튼에만 있습니다.

종류기본올림 · 누름Disabled

크기

버튼은 1024px 이하에서도 크기가 바뀌지 않습니다. 하단 고정 버튼과 바텀시트 버튼만 LG 54를 씁니다. 숫자는 실제 화면에서 잰 값입니다. 3-4

크기높이 · 글자쓰는 자리
SM36 · 14/20PC 입력칸 옆, 검색 영역, 표 안, 작은 보조 동작
MD48 · 16/24모달 버튼, 일반 주요 동작, 모바일 입력칸 옆
LG54 · 18/26모바일 하단 고정 버튼, 바텀시트 하단 버튼

좌우 여백은 모든 크기에서 16, 모서리 4(둥근 모양 999), 아이콘과 글자 사이 8. 너비는 글자에 맞춰 늘어나고 공통 최소 너비는 두지 않습니다. 모달 버튼만 기본 150입니다.

사용 예

검색 영역 하단

초기화(외곽선) + 검색(채움), 각 130×36, 사이 10, 가운데 정렬. 3-7

입력칸 옆 버튼

모바일에서는 입력칸과 같은 높이 48(MD)을 씁니다. PC는 칸 40과 같은 높이의 버튼이 없어 SM 36을 칸 가운데에 맞춥니다. ds-btn--field 하나로 화면 폭에 따라 자동으로 바뀝니다.

사용 원칙

이렇게

주 동작 하나만 채움. 무엇을 누르면 되는지 바로 보입니다.

이렇게 하지 않기

둘 다 채우면 초기화를 잘못 눌러 조건이 지워지기 쉽습니다.

이렇게

라벨은 눌렀을 때 일어나는 일을 그대로 씁니다.

이렇게 하지 않기

“네 / 아니요”는 질문을 다시 읽어야 뜻을 알 수 있습니다.

이렇게

모바일에서는 버튼을 칸과 같은 높이 48로 맞춥니다.

이렇게 하지 않기

칸은 48인데 버튼만 36이면 한 줄의 높이가 어긋나 보이고, 손가락으로 누르기도 작습니다.

기본 마크업

.ds-btn + 종류 1개 + 크기 1개를 조합합니다. 크기를 빼면 SM 36입니다.

<button class="ds-btn ds-btn--primary ds-btn--md" type="button">주문하기</button>
<button class="ds-btn ds-btn--outline-secondary" type="button">우편번호 찾기</button>
<button class="ds-btn ds-btn--primary" type="button" disabled>저장</button>

<!-- 아이콘 버튼: 라벨은 aria-label로 -->
<button class="ds-btn ds-btn--outline-secondary ds-btn--icon" type="button" aria-label="검색">
  <span class="ds-btn__icon"></span>
</button>
