주 버튼 채움

팔레트

역할별 10단계. 칸을 누르면 색 값이 복사됩니다. 점이 찍힌 칸은 의미 색에서 실제로 쓰는 단계입니다.

이로움돌봄 테마는 브랜드 줄만 orange로 바뀝니다(Figma Theme 모드). 나머지 역할은 두 테마가 같습니다.

의미 색

화면을 만들 때 고르는 색입니다. Figma 이름 그대로 적었습니다. “Primitive”는 버튼·선택처럼 누르는 요소에 쓰는 색 묶음입니다.

상태 색 세트

상태는 배경(연함) + 테두리 + 글자(진함) 세 가지를 한 벌로 씁니다. 상태칩·알림 박스가 이 조합입니다. Status Chip

글자 대비

흰 배경 위 글자색의 명도 대비입니다(이 화면에서 계산). 본문은 4.5 이상이 기준입니다.

회색 #999(tertiary)와 #BDBDBD(disabled)는 4.5에 못 미칩니다. 비어 있는 글자 수·비활성처럼 읽지 않아도 되는 글자에만 씁니다.

테마

같은 화면을 이로움돌봄 테마로 바꾸면 브랜드 색만 바뀝니다.

배송완료 선택된 옵션

이 미리보기는 의미 색만 써서 그렸습니다. 지금 컴포넌트 CSS 일부는 팔레트 색을 직접 써서 테마를 따르지 않습니다. 이로움돌봄 화면을 만들 때 의미 색으로 바꿔야 합니다.

변수 이름 규칙

층CSS 변수Figma 이름
팔레트--ds-color-darkblue-600Color/Darkblue/600
역할--ds-color-brand-600 (brand · neutral · info · success · danger · brand-sub · warning)Color/brand/600
의미--ds-color-{text|bg|border|icon}-{이름}Color/text/primary
누르는 요소--ds-color-bg-control-primary, …-primary-hoverColor/bg/Primitive/primary, …primary-hover:active

바꾼 표기: Primitive → control, hover:active → hover, teritiary → tertiary, brandSub → brand-sub. 원래 Figma 이름은 tokens.css 주석과 tokens.json의 figma 항목에 남아 있습니다.

쓰는 법

.notice { background: var(--ds-color-bg-info-subtle); border: 1px solid var(--ds-color-border-info-subtle); color: var(--ds-color-text-info-bold); }

<!-- 이로움돌봄 테마: 감싸는 요소에 클래스 하나 -->
<body class="ds-theme-dolbom">…</body>

tokens.css는 직접 고치지 않습니다. tokens/figma-variables.json을 고친 뒤 node design-system/tools/build-tokens.js를 실행하면 tokens.css · typography.css · tokens.json이 함께 만들어집니다.
