Radio Components · Select 여러 항목 중 하나만 고를 때 씁니다. 하나를 고르면 다른 하나는 자동으로 풀립니다. Figma · Radio ↗ 정책 3-7 검색 영역 ↗ 20×20 · PC·모바일 같은 크기

개요

대여 주문요청 관리의 품목 필터입니다. 다른 항목을 누르면 앞의 선택이 풀립니다. 방향키로도 옮겨 다닐 수 있습니다.

화면

언제 쓰나요

  • 항목이 2~5개이고 하나만 고를 때 — 품목, 기간, 연락 방법
  • 모바일 필터는 모두 하나만 고르므로 Radio입니다. 3-7
  • 항목이 많으면 Select, 여러 개를 고르면 Checkbox를 씁니다.

구조

  1. 1원 — 20×20. 고르면 브랜드 색으로 채우고 가운데 흰 점 10.
  2. 2라벨 — 14 / 줄높이 20. 라벨을 눌러도 선택됩니다.
  3. 3묶음 — 같은 묶음에서는 하나만 선택됩니다.

상태

비활성 + 선택의 가운데 점은 #BDBDBD입니다. 흰 점이 회색 바탕에서 보이지 않아 Checkbox 비활성 체크와 같은 색으로 맞췄습니다(2026-10-15, Figma도 수정).

사용 원칙

이렇게

처음부터 하나가 골라져 있게 합니다(필터는 “전체”).

이렇게 하지 않기

아무것도 안 고른 채 시작하면, 한 번 고른 뒤에는 “안 고름”으로 되돌릴 수 없습니다.

이렇게

켜고 끄는 한 가지는 체크박스.

이렇게 하지 않기

라디오 하나만 두면 한 번 켠 뒤 끌 수 없습니다.

기본 마크업

브라우저 기본 input type="radio"를 씁니다. 같은 묶음은 같은 name을 주면 하나만 선택되고, 방향키로 옮겨 다닙니다.

<div class="ds-choice-group" role="radiogroup" aria-label="품목">
  <label class="ds-radio">
    <input class="ds-radio__input" type="radio" name="item" value="all" checked>
    <span class="ds-radio__label">전체</span>
  </label>
  <label class="ds-radio">
    <input class="ds-radio__input" type="radio" name="item" value="bed">
    <span class="ds-radio__label">전동침대</span>
  </label>
</div>
