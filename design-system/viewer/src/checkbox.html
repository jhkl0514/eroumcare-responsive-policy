Checkbox Components · Select 여러 항목 중 필요한 만큼 고르거나, 한 가지에 동의할 때 씁니다. 하나만 골라야 하면 Radio를 씁니다. Figma · checkbox ↗ 정책 3-7 검색 영역 ↗ 20×20 · PC·모바일 같은 크기

개요

검색 영역의 품목 필터입니다. 직접 눌러 보세요. “전체”와 각 항목이 정책 3-7 규칙대로 함께 움직입니다.

화면

언제 쓰나요

  • 여러 개를 함께 고를 때 — 검색 필터의 품목 · 상태
  • 한 가지를 확인하거나 동의할 때 — “주문 변경 내용을 확인했습니다”

구조

  1. 1상자 — 20×20, 모서리 4. 고르면 브랜드 색으로 채우고 흰 체크.
  2. 2라벨 — 14 / 줄높이 20. 라벨을 눌러도 선택됩니다.
  3. 3묶음 — 가로로 놓고, 자리가 모자라면 다음 줄로.

기본 마크업

브라우저 기본 input type="checkbox"를 그대로 씁니다. 키보드(Tab · Space)와 화면낭독기가 따로 손대지 않아도 동작합니다.

<div class="ds-choice-group" role="group" aria-label="품목" data-ds-check-all>
  <label class="ds-check">
    <input class="ds-check__input" type="checkbox" name="item" value="all" checked>
    <span class="ds-check__label">전체</span>
  </label>
  <label class="ds-check">
    <input class="ds-check__input" type="checkbox" name="item" value="bed">
    <span class="ds-check__label">전동침대</span>
  </label>
</div>
