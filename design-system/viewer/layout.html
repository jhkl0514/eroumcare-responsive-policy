간격 단계와 화면 폭 기준입니다. 1024px을 기준으로 PC와 모바일이 나뉘고, 줄바꿈은 정해진 폭 공식으로 일어납니다.

Figma · spacing · Breakpoint ↗ 정책 3-2 입력 폼 배치 ↗ 1024 · 360

간격은 이 14단계 안에서만 고릅니다. 막대 길이가 실제 크기입니다.

입력 폼 배치

라벨 125 고정 + 입력 영역 최소 폭. 화면이 줄어 둘이 한 줄에 안 들어가는 순간 라벨이 위로 올라갑니다. 줄바꿈 지점은 미디어쿼리가 아니라 이 공식의 결과입니다. 아래 막대를 움직여 보세요.

.form-row { display: flex; flex-wrap: wrap; align-items: flex-start; column-gap: 4px; row-gap: 8px; }
